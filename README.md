# neon-ink-site

Landing page for [Neon Ink](https://github.com/thevibegarage/neon-ink), a free Claude skill.

Static site: `index.html` plus `img/`. No build step.

## Before going live

- Signup: set the form's `action` in `index.html` (search for `FORM_ACTION_URL`) to your email provider's form URL. Until then the signup section hides itself.
- Link previews: set `og:image` to the absolute URL of `img/palette.png`.
